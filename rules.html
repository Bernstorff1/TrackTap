How do playlists work?

Tapster collects song requests into one shared queue, where guests vote and the DJ controls playback. Queue position is determined by score.

1) Guests add tracks

Guests can add a track to the queue. New tracks start at the bottom of the queue and receive a score based on upvotes and downvotes.

2) Votes determine order

Upvotes and downvotes affect score. If two tracks have the same score, the one that reached that score first stays above. New tracks start at the bottom.

3) Boosts vs. organic votes

Boosts are paid votes. Organic votes are normal upvotes. Scoreboard and profile pages show them separately, but both count toward total score.

4) DJ pick

The DJ can mark a track as a DJ pick. It gets a high base score and stays at the top, but guests can still vote it up or down.

5) Played list

When a track is played, it moves to "Played". It can return to the queue later, but only once at a time.

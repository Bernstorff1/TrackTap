⚠️ Important Info About Spotify Jam

Spotify may automatically suggest or create a Jam for guests on the same WiFi - even if you did not start one yourself.

To maintain control, we recommend that you:

Start the Jam yourself immediately.

Open Jam settings.

Select "Only the host can control".

Otherwise, participants may skip the queue and play music directly.

🎧 Important Playback Information

Tapster only works correctly if you play audio via AirPlay (or cable) and not via Spotify Connect.

If you use Spotify Connect, the DJ feature will not function properly.
